## 📌 Project Overview

The **Adidas Sales Review Dashboard** is an Excel-based sales analytics
project designed to present key business metrics in a clear, visual, and
easy-to-explore format. It brings important sales indicators and
breakdowns together on one screen, helping users review performance
across products, cities, retailers, regions, and sales methods.

The dashboard uses KPI cards, charts, and slicers to make it easier to
explore the data and compare different segments.

## 🎯 Project Objectives

-   📈 Summarize overall sales performance using key performance
    indicators (KPIs).
-   👟 Compare units sold across Adidas product categories.
-   🌎 Explore sales activity across cities and regions.
-   🏬 Review performance by retailer.
-   🛍️ Compare sales methods, including **In-store**, **Online**, and
    **Outlet**.
-   🔎 Make the report easier to explore using interactive slicers.

## 📊 Dashboard KPIs

The dashboard displays the following headline metrics:

  -----------------------------------------------------------------------
  KPI                                 What it tells us
  ----------------------------------- -----------------------------------
  💰 **Total Sales**                  The total sales value represented
                                      in the dataset

  📈 **Operating Profit**             The operating profit represented in
                                      the dataset

  📦 **Units Sold**                   The total number of units sold

  🎯 **Margin**                       The profit margin percentage

  🏷️ **Average Price**                The average price value shown by
                                      the dashboard
  -----------------------------------------------------------------------

> **Note:** KPI values shown in a screenshot are examples from the
> current report view. Confirm that each KPI is correctly calculated and
> responds to slicer selections before using it for business decisions.

## 📉 Visuals Included

-   **City-wise chart** 🏙️ --- compares the displayed measure across
    cities.
-   **Product category chart** 👕 --- compares units sold across product
    categories.
-   **Sales method doughnut chart** 🛒 --- shows the distribution across
    In-store, Online, and Outlet.
-   **Region comparison chart** 🗺️ --- compares the displayed measure
    across regions.
-   **Retailer pie chart** 🏬 --- shows the breakdown of sales by
    retailer.

## 🔍 Interactive Filters

The dashboard includes slicers for:

-   👕 **Product**
-   🏬 **Retailer**
-   🗺️ **Region**
-   🏙️ **City**

Use these filters to focus the report on selected categories and compare
how the displayed results change. The dashboard also includes a
sales-method filter in the visual area.

## 💡 Key Insights to Explore

Use the dashboard to investigate questions such as:

1.  **Which product category has the highest units sold?**
2.  **Which cities show higher or lower activity for the selected
    measure?**
3.  **How do the regions compare with one another?**
4.  **How are sales distributed across retailers?**
5.  **What share of activity comes from In-store, Online, and Outlet
    sales?**
6.  **How do the headline KPIs change when a product, retailer, city, or
    region is selected?**

*The answers depend on the current filters and the underlying dataset.
Use the interactive dashboard to verify each insight rather than
assuming a fixed ranking.*

## 🚀 How to Use

1.  Open the Excel workbook containing the dashboard.
2.  Review the KPI cards at the top for a quick overview.
3.  Select a value in a slicer such as **Product**, **Retailer**,
    **Region**, or **City**.
4.  Observe how the connected charts and KPIs respond.
5.  Clear the filter to return to the broader view.
6.  Compare different selections to explore patterns in the data.
